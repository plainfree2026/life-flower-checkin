# 生命之花平衡轮 · 打卡工作台

基于古典「生命之花（Life Balance Wheel）」八维度人生规划法，做的一个**单文件可交互打卡工作台**。

> 把人生想成一朵慢慢绽放的花，8 个维度就是 8 片花瓣：职业发展、财务、健康、娱乐休闲、家庭、朋友重要他人、个人成长、自我实现。

## 功能

- **中央八瓣花**：按评分实时「开花」。紫色=目标型（职业/财务/成长/自我实现），绿色=关系型（健康/休闲/家庭/朋友）。
- **8 张维度卡片**：可设当前评分（0–10）、年度目标分、今年最重要的 3 件事、每日打卡（带备注 + 连续天数）。
- **顶部三指标**：绽放度（8 维平均分）、总打卡数、连续天数。
- **月度绽放时间线**：每月底存一张快照，看花一年比一年开得大。
- **导出 / 导入 / 重置**：建议每月导出 JSON 备份。

## 用法

直接用浏览器打开 `生命之花打卡工作台.html` 即可，**无需联网、无需服务器**。

1. 拖动每瓣滑块给现状打分（0–10），花瓣同步变化；
2. 在每个维度填「今年最重要的 3 件事」；
3. 每天做了哪瓣的事，去对应卡片点「打卡」写一句备注；
4. 每月底保存快照，年底回看时间线。

## 数据隐私

所有数据保存在**你本机浏览器的 localStorage**，不上传任何服务器。换设备或清缓存前，记得用「导出」功能备份 JSON。
